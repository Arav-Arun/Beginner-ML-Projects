# Cat vs Dog Image Classifier

A complete CNN project that classifies every cat and dog image available in CIFAR-10. It runs in a fresh Colab session without credentials.

## Run it

Open [`cat_vs_dog_classifier.ipynb`](cat_vs_dog_classifier.ipynb) from the repository root and select **Run all**. Use a GPU runtime if you want faster training, though the project also works on CPU.

## Data and attribution

Cat and dog images are extracted from CIFAR-10, downloaded automatically via TensorFlow/Keras on first run. The full code and explanations are included in this repository.

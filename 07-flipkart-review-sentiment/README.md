# Flipkart Reviews Sentiment Analysis

A fast NLP notebook that converts product-review ratings into positive/negative labels, trains a TF-IDF plus logistic-regression model, and predicts new review sentiment.

## Run it

Open [`flipkart_review_sentiment.ipynb`](flipkart_review_sentiment.ipynb) from the repository root and select **Run all**. The roughly 1 MB CSV is included at `data/flipkart_reviews.csv`.

## Data and attribution

The full dataset, code, and explanations are included in this repository.
